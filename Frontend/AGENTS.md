# ESIA storefront

React + Vite storefront and admin demo for the ESIA shop experience.

## Project structure

- `src/main.tsx` – React entry point
- `src/App.tsx` – main app flow and routing
- `src/index.css` – global styles and Tailwind import
- `index.html` – Vite HTML shell
- `package.json` – project scripts and dependencies
- `vite.config.ts` – Vite setup

## Scripts

- `npm run dev` – start the Vite dev server
- `npm run build` – build the production bundle
- `npm run preview` – preview the production build

## Styling

This project uses Tailwind CSS v4 via the Vite plugin. Keep utility classes in JSX and place any additional global styles in `src/index.css`.
